Selected Projects

PCANN — Protein–Protein Binding Affinity Prediction

PyTorch / PyTorch Geometric

Developed a graph neural network for predicting protein–protein binding affinity from 3D protein structures. Built the data preparation and graph construction pipeline using features from the pretrained ESM-2 protein language model, and implemented training, validation, and testing of a Graph Attention Network (GAT). On two independent test datasets, the model reduced MAE by approximately 7% on average compared with the publicly available baseline method.
